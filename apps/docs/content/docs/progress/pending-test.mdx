# Pending Tests

The current release needs manual verification in these areas:

- Core immutable document contract: loading or adding externally owned nodes should not retain mutable array, node, or position references, and invalid coordinates or dimensions should be reported or rejected.
- Core initialization and interaction optimization: consumers should initialize instances with `initialDocument` and `initialViewport`, continue loading later snapshots through commands, and preserve connection targeting, group drop targeting, undo, redo, and upstream-node lookup behavior.
