# Pending Tests

The current release needs manual verification in these areas:

- Core virtualization hook: with at least one thousand mixed image/video nodes, only viewport-local media DOM and adjacent connections should remain mounted while fast pan and zoom keep a sufficient overscan buffer.
- Core SSR and frame scheduling: importing and server-rendering React entry points should not access browser globals or emit layout-effect warnings, while browser pointer moves still coalesce to the latest frame value.
- Core controlled state: document-only, viewport-only, and fully controlled instances should publish command updates, accept authoritative replacements, preserve optimistic command reads, and clear stale history or interaction when the host replaces a document.
- Core connection ports: source and target handle IDs should survive creation, validation, node updates, copy/paste, history, custom path rendering, undo, and redo.
- Core viewport validation: initialization and command updates should reject NaN, Infinity, zero, or negative zoom values without corrupting the last valid viewport.
- Core API documentation: generated declarations and editor tooltips should expose the new ownership, history, coordinate-system, and performance notes for public types and functions.
- Core connection culling: panning a large graph should omit fully off-screen ordinary SVG connections while keeping selected, active, and newly created connections available.
- Core pointer coalescing: rapid node dragging, marquee selection, and connection targeting should stay visually responsive, commit the final pointer coordinate, and remain isolated by pointer ID.
- Core large-canvas spatial index: pan, zoom, marquee selection, connection targeting, group nodes, and off-screen image or video node culling should preserve document order and hit behavior with at least one thousand nodes.
- Core immutable document contract: loading or adding externally owned nodes should not retain mutable array, node, or position references, and invalid coordinates or dimensions should be reported or rejected.
- Core initialization and interaction optimization: consumers should initialize instances with `initialDocument` and `initialViewport`, continue loading later snapshots through commands, and preserve connection targeting, group drop targeting, undo, redo, and upstream-node lookup behavior.
