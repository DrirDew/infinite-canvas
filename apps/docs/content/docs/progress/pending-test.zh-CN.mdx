# 待测试

- Core 命令架构：现有扁平命令和独立回调应保持兼容，集中式 `policies` 与 `listeners` 配置应产生一致的连线、分组和状态订阅行为。
- Core 事务与交互不变量：无效 transaction 或 preview 结果应被拒绝且不改变历史，拖动、缩放和连线应只暴露一个互斥的交互 `kind`，同时保留原有布尔字段。
- Core 初始化与交互优化：接入方应通过 `initialDocument` 和 `initialViewport` 初始化实例，后续快照仍通过命令加载；连线目标命中、分组拖入目标、撤销重做和上游节点查询行为应保持不变。
