# 快速开始

如果你只是想先把项目跑起来，优先部署或启动 `web/` 前端。公司腾讯云点播还需要 `server/`。

## Vercel 部署

在 Vercel 中导入仓库即可，根目录 `vercel.json` 会构建 `web/`。个人渠道仍由浏览器前台直连。这条静态部署路径没有公司腾讯云点播。

## 本地启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

若要启用公司腾讯云点播，把 `.env.example` 复制为 `.env` 并填写腾讯云变量，再另开终端：

```bash
cd server
bun run dev
```

## Docker 启动

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## 首次使用建议

- 配置了公司腾讯云点播后，生图工作台应直接出现公司模型，不用在配置里填密钥。
- 个人渠道仍可在右上角配置弹窗填写 `Base URL`、`API Key` 和模型名。
- 如果需要提示词仓库内容，打开 `/prompts` 会由浏览器前端直连拉取并缓存到 IndexedDB。
- 如果需要跨设备同步画布、素材和生成记录，可在配置弹窗中填写 WebDAV。

## 说明

- 当前画布项目和“我的素材”主要保存在浏览器本地，WebDAV 同步需要用户自行配置。
- 个人渠道的 API Key 只缓存在当前浏览器会话，关闭后消失。共享渠道密钥存在服务端；管理员可在配置页睁眼查看并随配置一起导出，普通用户只能看到掩码，导出也不含共享渠道。
