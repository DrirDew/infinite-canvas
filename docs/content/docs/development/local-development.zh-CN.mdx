# 本地开发

本仓库不在宿主机安装 bun / node。改代码后用 Docker 重新构建并启动。

把项目根目录 `.env.example` 复制为 `.env`，至少填写 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD`。要用公司渠道时再填腾讯云三项。

```bash
docker compose -f docker-compose.local.yml up -d --build
```

打开 `http://localhost:3000`，用管理员账号登录。用户表为空时，会用 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 创建第一个管理员。管理员可在配置页「团队账号」里创建同事账号。

用户数据在 `./data/app.db`。只有管理员能打开配置；公司渠道只读，不展示密钥。

改过 `web/` 或 `server/` 后必须带 `--build`。只改 `.env` 时用 `docker compose -f docker-compose.local.yml up -d` 让容器读到新变量即可。`ADMIN_PASSWORD` 只在空库时写入，库里已有用户后改这项不会改已有密码。

文档站仍是独立镜像，需要时在 `docs/` 里单独 compose。

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改登录和公司腾讯云点播代签：主要看 `server/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
