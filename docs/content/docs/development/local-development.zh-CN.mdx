# 本地开发

当前主应用以 `web/` 前端为主。个人渠道仍由浏览器直连；公司腾讯云点播由 `server/` 代签，密钥放在仓库根目录 `.env`。

## 1. 启动前端

```bash
cd web
bun install
bun run dev
```

前端默认访问：

```text
http://localhost:3000
```

## 2. 启动公司渠道服务（可选）

把 `.env.example` 复制为 `.env`，填写 `TENCENT_VOD_SECRET_ID`、`TENCENT_VOD_SECRET_KEY`、`TENCENT_VOD_SUB_APP_ID` 后：

```bash
cd server
bun run dev
```

前端会把 `/api` 转到这个服务。不启动时，工作台不显示公司渠道，个人渠道仍可在配置里自行填写。

## 3. 配置模型

打开右上角配置弹窗。公司渠道只读，不展示密钥。个人渠道仍填写自己的 `Base URL`、`API Key` 和模型名。

## 4. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改公司腾讯云点播代签：主要看 `server/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
