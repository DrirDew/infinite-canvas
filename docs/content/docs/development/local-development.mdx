# Local Development

This repository is started with Docker. Do not install bun or Node on the host.

Copy `.env.example` to `.env` in the repository root and set `ADMIN_USERNAME` and `ADMIN_PASSWORD`. Add the Tencent Cloud variables if you want the company provider.

```bash
docker compose -f docker-compose.local.yml up -d --build
```

Open `http://localhost:3000` and sign in. The first admin is created from `ADMIN_USERNAME` / `ADMIN_PASSWORD` when the user table is empty. Admins can create teammate accounts in Settings → Team accounts.

User data is stored in `./data/app.db`. Only admins can open Settings. Company providers are read-only and do not show secrets.

Rebuild with `--build` after changing `web/` or `server/`. If you only changed `.env`, `docker compose -f docker-compose.local.yml up -d` is enough. `ADMIN_PASSWORD` is written only when the database is empty; changing it later does not update an existing admin.

The documentation site is a separate image. Use Compose in `docs/` when you need it.

Common locations:

- Canvas, pages, and interactions: `web/`
- Login and company Tencent Cloud VOD signing: `server/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
